# PromptBoard — Vibe Coding Prompt for Trae + Mimo 2.5 Pro

## 一句话
单页 HTML，vanilla JS + CSS，零依赖。包豪斯风格UI，多模型接入，自然语言→优秀prompt的转换工具，本地自用。

---

## 1. 包豪斯风格 UI 规范

### 色彩
- 主色：黑 #111111、白 #F5F5F5、灰 #888888
- 点缀色（仅用于状态指示和交互反馈，不要大范围使用）：
  - 红 #E53935（未配置/错误）
  - 黄 #FDD835（已配置未使用）
  - 蓝 #1E88E5（就绪/活跃）

### 字体
- font-family: 'Inter', system-ui, -apple-system, sans-serif
- 标题粗体，正文常规，用大小对比代替多余装饰
- 全站无圆角（border-radius: 0）

### 几何与分割
- 粗黑线（2px solid #111）作为横向区域分割
- 内容左对齐，块状矩形，无阴影无渐变
- 按钮为纯色矩形块：白底黑字 + 1px 黑边，hover 时填充黑色，文字变白

### 状态圆点
- 直径 10px 的实心圆，三原色（红黄蓝）
- 用于模型配置卡片顶部的状态指示

### 详细区域说明

#### 顶部标题区
- 左侧"PromptBoard"，粗体大号
- 右侧小字显示当前模式："规则模式" / "AI增强模式"

#### 左侧：输入区 + 模板
- textarea：占满左区域上部约 60%，placeholder="用自然语言描述你想要的 AI 助手..."
- 下方模板：5个横向排列的选项卡片，短单词：
  - General / Role / COT / Writing / Code
  - 选中态：黑底白字
  - 未选中态：白底黑字 + 1px灰边

#### 右侧：输出区
- 上半部：只读 textarea 或 pre，等宽字体展示生成的 prompt
- 下半部：[复制到剪贴板] 按钮

#### 底部中间：模型配置区
- 一排水平排列的模型名称 + 状态圆点
- 内置模型列表（默认折叠，点击展开配置面板）：
  | 名称 | 默认 Base URL | 默认模型名 |
  |------|--------------|-----------|
  | Mimo | （留空，用户填入） | （留空，用户填入） |
  | DeepSeek | https://api.deepseek.com | deepseek-chat |
  | OpenAI | https://api.openai.com/v1 | gpt-4o-mini |
  | 自定义 | （留空，用户填入） | （留空，用户填入） |
- 点击模型名展开该模型的配置卡片，包含：
  - API Key：type=password，placeholder="sk-..."
  - Base URL：input，预填默认值
  - Model Name：input，预填默认值
  - [保存] 按钮
- 每个模型顶部左侧有一个 10px 状态圆点：
  - 红：未配置（Key 为空）
  - 黄：已配置但未切换使用过
  - 蓝：当前活跃模型（AI模式下调用此模型）

#### 底部右侧：模式切换
- 两个并排按钮：[规则模式] [AI增强模式]
- 当前模式填充黑底白字，另一模式白底黑字灰边

## 3. 核心功能逻辑

### 规则模式（默认）
- 内置 5 套 prompt 骨架，每个骨架包含结构化的字段占位符
- 用户输入自然语言后，做关键词匹配分类（简单实现：if 包含"故事/恐怖/角色"等关键词则匹配 Role，if 包含"步骤/分步"则匹配 COT 等）
- 将匹配到的骨架填充用户输入内容，直接输出到右侧
- 不调 API，完全本地

### AI 增强模式
- 用户需至少配置一个模型的 API Key
- 将用户自然语言 + 选中的骨架名称/描述拼接成一段 meta-prompt，发给当前活跃模型
- meta-prompt 格式示例（发给模型的 system message）：
  > 你是一个 Prompt 工程师。用户以自然语言描述了他想要的 AI 角色，请将其重写为结构化的、可直接使用的 Prompt。
  > 用户选择的模板类型：[选中骨架名称]
  > 骨架结构要求：[该骨架的字段说明]
  > 用户原始描述：[用户的自然语言输入]
  > 
  > 请输出结构化的 Prompt，不要输出多余的解释。
- 使用标准 OpenAI 兼容格式调用：POST /v1/chat/completions
- 请求体：{ "model": "配置的模型名", "messages": [...], "temperature": 0.7 }
- 输出展示在右侧输出区

### localStorage
- history：最近 10 条（{ input, output, template, model, timestamp }），点击回填 input 到输入区
- modelConfigs：每个模型的 { apiKey, baseUrl, modelName, active }
- 暗色模式偏好（如果有）

## 4. 技术要求
- 单文件 .html，vanilla JS，零 npm 零 CDN 零框架
- 所有 API 调用用 fetch，禁止 XMLHttpRequest
- 响应式：最小宽度 800px，低于 800px 时左右布局变为上下布局
- 页面加载时检查 localStorage，恢复上次使用的模型和模式
- 暗色模式支持：切换时整个页面黑白反转，点缀色做对应调整

---

## 5. 交互细节
- 切换模型时，配置面板平滑折叠/展开（CSS transition）
- 复制按钮：复制成功提示"已复制"文字反馈，2秒后消失
- 输入区输入时不做实时分析，用户主动点击"生成"或按 Ctrl+Enter 触发
- AI 模式下调用 API 时，输出区显示加载状态（文本 "正在生成..."）
